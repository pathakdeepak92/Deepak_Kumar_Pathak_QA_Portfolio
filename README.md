# Deepak Kumar Pathak - QA Portfolio

A professional single-page portfolio website for a QA / Software Testing professional with 11+ years of experience.

## Files
- index.html
- style.css
- script.js

## Customize before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- Generic experience/project placeholders with your actual information.

## Publish for free
### GitHub Pages
1. Create a GitHub account.
2. Create a repository named `YOURUSERNAME.github.io`.
3. Upload these three website files.
4. Enable GitHub Pages in repository Settings > Pages.
5. Your public URL will be `https://YOURUSERNAME.github.io/`.

### Netlify / Vercel
Upload the folder as a static site. No PHP/database/server is required.

## Privacy
Do not publish home address, personal ID numbers, salary, confidential project/client information, passwords or private documents.
